地點：台北市 / 混合辦公

【團隊與工作內容】
品質工程團隊 4 人，目標是把目前以人工為主的回歸測試轉為自動化，
並把測試整合進每日的 CI 流程。

【必備條件】
1. 3 年以上軟體測試經驗，其中至少 1 年為自動化測試
2. 具備程式能力（Python、JavaScript 或 Java 擇一），能獨立撰寫與維護測試程式
3. 熟悉端對端測試框架（Playwright、Cypress 或 Selenium 擇一）
4. 具備 API 測試經驗，能自行設計測試資料與驗證邏輯
5. 能撰寫 SQL 查詢以驗證資料正確性
6. 具備將測試整合進 CI 流程的經驗（GitHub Actions、GitLab CI、Jenkins 擇一）
7. 能撰寫清楚的測試計畫與缺陷報告

【加分條件】
1. 具備效能測試經驗（JMeter、k6 擇一）
2. 熟悉測試金字塔概念並能與開發團隊討論測試分層
3. 有行動裝置或跨瀏覽器測試經驗
4. 具備測試環境與測試資料管理的經驗
