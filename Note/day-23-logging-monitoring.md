### 預算告警是監控的一部分，但它保護的範圍很窄

Day 04 設了預算，但只寫到「兩個都設了」。完整的坑在這裡。

**上限只涵蓋一個服務。** 設定畫面上有一行小字：這個上限只涵蓋 Vertex AI 的隨需費用。

但這個專案會用到 Cloud Run、Cloud Build、Cloud Storage、Cloud Logging、Cloud Trace，
這些都不在上限裡。而真正失控的風險反而常在這些地方，
像是一個忘記關掉的 Cloud Run 執行個體，它可以安靜地跑一整個月。

所以那個「僅傳送警告」的預算，範圍要選整個專案、不指定服務。

**一個我還沒搞懂的欄位。** 設完之後同一個畫面上有兩句互相矛盾的話：
摘要區寫「重新開始計算的時間：永不」，範圍區卻寫「時間範圍：每月」。

每月重置的話每個月有 $10，永不重置的話 $10 是整段期間的總額度，差一倍。
合理的猜測是「永不」指服務被暫停之後不會自動恢復，「每月」指金額的計算週期，但這是猜測。

「強制執行支出上限」還掛著預先發布版的標籤。
一個你看不懂的保險絲，不該是你唯一的保險絲。

**費用要去哪裡看，有三層。**

第一層是 `usage_metadata`，唯一不用等帳單的來源，SDK 跟著回應一起給你。
要算「這一次分析多少錢」只能靠它。

第二層是 Console 帳單報表（Billing → Reports，Filters 選 Vertex AI），
有數小時到 24 小時延遲，適合回頭覆盤，不適合即時監控。

第三層是預算告警，它是保險絲不是儀表板。

單價查[官方定價頁](https://cloud.google.com/vertex-ai/generative-ai/pricing)，不要憑記憶寫數字。
